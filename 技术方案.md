## 🤖 Assistant

下面给你一个 **MCP 技术方案**，目标是：

> 在代码编辑工具里，让模型不再直接自由生成 HTML，而是让模型调用 MCP 工具，提交结构化数据，MCP 服务端用固定模板渲染 HTML，从而保证输出格式、结构、样式稳定一致。

核心思路是：

```text
用户需求
  ↓
代码编辑器里的 AI Agent
  ↓
MCP Tool: render_html
  ↓
结构化 JSON 参数
  ↓
MCP Server 校验 JSON
  ↓
固定模板渲染
  ↓
生成稳定 HTML 文件
```

---

# 1. 总体架构

## 1.1 你要实现的不是“让模型写 HTML”

而是：

```text
模型只负责提取内容和页面语义
MCP 负责生成最终 HTML
```

也就是说，模型不再输出：

```html
<!DOCTYPE html>
<html>
...
</html>
```

而是调用一个工具：

```json
{
  "title": "产品介绍页",
  "description": "一个现代化产品落地页",
  "theme": "modern-blue",
  "sections": [
    {
      "type": "hero",
      "heading": "让 AI 工作流更稳定",
      "subheading": "用 MCP 把输出格式从提示词中解放出来",
      "cta": {
        "label": "立即开始",
        "href": "#start"
      }
    },
    {
      "type": "features",
      "heading": "核心优势",
      "items": [
        {
          "title": "格式稳定",
          "body": "HTML 结构由模板控制，不受模型风格影响。"
        }
      ]
    }
  ]
}
```

MCP 服务端把这个 JSON 变成固定 HTML。

---

# 2. 推荐方案：自定义 MCP Server

建议你做一个本地 MCP Server，提供以下工具。

## 2.1 MCP Tools 设计

### Tool 1：`render_html`

只返回 HTML 字符串，不写文件。

适合：

- 让 Agent 预览 HTML；
- 复制 HTML；
- 调试模板。

### Tool 2：`render_html_file`

生成 HTML 并写入项目文件。

适合你在代码编辑器里直接生成：

```text
./output/index.html
```

或者：

```text
./src/pages/landing.html
```

### Tool 3：`list_html_templates`

列出可用模板。

例如：

```json
[
  "landing-page",
  "report",
  "article",
  "dashboard",
  "email"
]
```

### Tool 4：`validate_html_input`

可选，用来只校验结构化输入，不渲染。

# 4. 技术栈建议

推荐用 TypeScript 写 MCP Server。

```text
Runtime: Node.js 20+
MCP SDK: @modelcontextprotocol/sdk
Schema 校验: zod
HTML 格式化: prettier
模板方案: 直接 TypeScript 模板函数，或 Handlebars/Nunjucks
```

我建议一开始不要上复杂模板引擎，直接用 TypeScript 函数生成 HTML。

原因：

1. 类型安全；
2. 方便控制结构；
3. 容易做条件渲染；
4. 不容易被模板注入；
5. 后续可以扩展多个模板。

# 5. JSON Schema 设计

你的核心是定义一个稳定的页面数据协议。

例如：

```ts
// src/schemas/htmlPageSchema.ts

import { z } from "zod";

export const ctaSchema = z.object({
  label: z.string(),
  href: z.string().default("#")
});

export const featureItemSchema = z.object({
  title: z.string(),
  body: z.string()
});

export const sectionSchema = z.discriminatedUnion("type", [
  z.object({
    type: z.literal("hero"),
    heading: z.string(),
    subheading: z.string().optional(),
    cta: ctaSchema.optional()
  }),

  z.object({
    type: z.literal("features"),
    heading: z.string(),
    intro: z.string().optional(),
    items: z.array(featureItemSchema).min(1)
  }),

  z.object({
    type: z.literal("content"),
    heading: z.string(),
    body: z.string()
  }),

  z.object({
    type: z.literal("steps"),
    heading: z.string(),
    items: z.array(
      z.object({
        title: z.string(),
        body: z.string()
      })
    ).min(1)
  }),

  z.object({
    type: z.literal("faq"),
    heading: z.string(),
    items: z.array(
      z.object({
        question: z.string(),
        answer: z.string()
      })
    ).min(1)
  })
]);

export const htmlPageSchema = z.object({
  template: z
    .enum(["landing-page", "report", "article", "dashboard"])
    .default("landing-page"),

  title: z.string(),
  description: z.string().optional(),

  lang: z.string().default("zh-CN"),

  theme: z
    .enum(["modern-blue", "minimal-gray", "warm-orange", "dark-tech"])
    .default("modern-blue"),

  sections: z.array(sectionSchema).min(1),

  footer: z
    .object({
      text: z.string().optional(),
      links: z
        .array(
          z.object({
            label: z.string(),
            href: z.string()
          })
        )
        .optional()
    })
    .optional()
});

export type HtmlPageInput = z.infer<typeof htmlPageSchema>;
```

这个 schema 就是你对模型输出的“硬约束”。

## 6.1 HTML 转义函数

不要直接拼用户输入，否则容易注入脚本。

```ts
// src/utils/escapeHtml.ts

export function escapeHtml(value: unknown): string {
  return String(value ?? "")
    .replaceAll("&", "&amp;")
    .replaceAll("<", "&lt;")
    .replaceAll(">", "&gt;")
    .replaceAll('"', "&quot;")
    .replaceAll("'", "&#039;");
}
```

## 6.3 渲染函数

```ts
// src/renderers/renderHtml.ts

import { HtmlPageInput } from "../schemas/htmlPageSchema";
import { escapeHtml } from "../utils/escapeHtml";
import { baseCss } from "./templates";

function renderSection(section: HtmlPageInput["sections"][number]): string {
  switch (section.type) {
    case "hero":
      return `
        <header class="section hero">
          <h1>${escapeHtml(section.heading)}</h1>
          ${
            section.subheading
              ? `<p>${escapeHtml(section.subheading)}</p>`
              : ""
          }
          ${
            section.cta
              ? `<a class="button" href="${escapeHtml(section.cta.href)}">${escapeHtml(section.cta.label)}</a>`
              : ""
          }
        </header>
      `;

    case "features":
      return `
        <section class="section">
          <h2>${escapeHtml(section.heading)}</h2>
          ${section.intro ? `<p class="muted">${escapeHtml(section.intro)}</p>` : ""}
          <div class="grid">
            ${section.items
              .map(
                item => `
                  <article class="card">
                    <h3>${escapeHtml(item.title)}</h3>
                    <p>${escapeHtml(item.body)}</p>
                  </article>
                `
              )
              .join("")}
          </div>
        </section>
      `;

    case "content":
      return `
        <section class="section">
          <h2>${escapeHtml(section.heading)}</h2>
          <p>${escapeHtml(section.body)}</p>
        </section>
      `;

    case "steps":
      return `
        <section class="section">
          <h2>${escapeHtml(section.heading)}</h2>
          <div class="steps">
            ${section.items
              .map(
                item => `
                  <article class="step">
                    <h3>${escapeHtml(item.title)}</h3>
                    <p class="muted">${escapeHtml(item.body)}</p>
                  </article>
                `
              )
              .join("")}
          </div>
        </section>
      `;

    case "faq":
      return `
        <section class="section">
          <h2>${escapeHtml(section.heading)}</h2>
          ${section.items
            .map(
              item => `
                <article class="faq-item">
                  <h3>${escapeHtml(item.question)}</h3>
                  <p class="muted">${escapeHtml(item.answer)}</p>
                </article>
              `
            )
            .join("")}
        </section>
      `;

    default:
      return "";
  }
}

export function renderHtmlPage(input: HtmlPageInput): string {
  const description = input.description ?? input.title;

  return `<!DOCTYPE html>
<html lang="${escapeHtml(input.lang)}">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>${escapeHtml(input.title)}</title>
  <meta name="description" content="${escapeHtml(description)}">
  <style>
${baseCss(input.theme)}
  </style>
</head>
<body>
  <main class="page">
    ${input.sections.map(renderSection).join("\n")}

    ${
      input.footer
        ? `<footer>
            ${input.footer.text ? `<p>${escapeHtml(input.footer.text)}</p>` : ""}
            ${
              input.footer.links?.length
                ? `<p>${input.footer.links
                    .map(link => `<a href="${escapeHtml(link.href)}">${escapeHtml(link.label)}</a>`)
                    .join(" · ")}</p>`
                : ""
            }
          </footer>`
        : ""
    }
  </main>
</body>
</html>`;
}
```

# 7. MCP Server 实现

下面是关键的 `src/index.ts`。

```ts
// src/index.ts

import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";
import { mkdir, writeFile } from "node:fs/promises";
import { dirname, resolve } from "node:path";
import prettier from "prettier";

import { htmlPageSchema } from "./schemas/htmlPageSchema";
import { renderHtmlPage } from "./renderers/renderHtml";

const server = new McpServer({
  name: "mcp-html-renderer",
  version: "1.0.0"
});

async function formatHtml(html: string): Promise<string> {
  try {
    return await prettier.format(html, {
      parser: "html",
      printWidth: 100,
      tabWidth: 2,
      useTabs: false
    });
  } catch {
    return html;
  }
}

function assertSafeOutputPath(path: string): string {
  const cwd = process.cwd();
  const fullPath = resolve(cwd, path);

  if (!fullPath.startsWith(cwd)) {
    throw new Error("Invalid output path: path traversal is not allowed.");
  }

  if (!fullPath.endsWith(".html")) {
    throw new Error("Invalid output path: only .html files are allowed.");
  }

  return fullPath;
}

server.tool(
  "list_html_templates",
  "List available HTML templates and themes.",
  {},
  async () => {
    return {
      content: [
        {
          type: "text",
          text: JSON.stringify(
            {
              templates: ["landing-page", "report", "article", "dashboard"],
              themes: ["modern-blue", "minimal-gray", "warm-orange", "dark-tech"],
              sectionTypes: ["hero", "features", "content", "steps", "faq"]
            },
            null,
            2
          )
        }
      ]
    };
  }
);

server.tool(
  "render_html",
  "Render a complete, stable, single-file HTML document from structured page data. Use this tool whenever the user asks for HTML output.",
  {
    page: htmlPageSchema
  },
  async ({ page }) => {
    const parsed = htmlPageSchema.parse(page);
    const html = await formatHtml(renderHtmlPage(parsed));

    return {
      content: [
        {
          type: "text",
          text: html
        }
      ]
    };
  }
);

server.tool(
  "render_html_file",
  "Render a complete, stable, single-file HTML document from structured page data and write it to a .html file in the current project.",
  {
    outputPath: z
      .string()
      .describe("Relative output path ending with .html, for example output/index.html."),
    page: htmlPageSchema
  },
  async ({ outputPath, page }) => {
    const parsed = htmlPageSchema.parse(page);
    const html = await formatHtml(renderHtmlPage(parsed));

    const fullPath = assertSafeOutputPath(outputPath);

    await mkdir(dirname(fullPath), { recursive: true });
    await writeFile(fullPath, html, "utf8");

    return {
      content: [
        {
          type: "text",
          text: JSON.stringify(
            {
              ok: true,
              outputPath,
              message: `HTML file generated successfully: ${outputPath}`
            },
            null,
            2
          )
        }
      ]
    };
  }
);

server.tool(
  "validate_html_input",
  "Validate structured page data before rendering HTML.",
  {
    page: htmlPageSchema
  },
  async ({ page }) => {
    const parsed = htmlPageSchema.parse(page);

    return {
      content: [
        {
          type: "text",
          text: JSON.stringify(
            {
              ok: true,
              page: parsed
            },
            null,
            2
          )
        }
      ]
    };
  }
);

const transport = new StdioServerTransport();
await server.connect(transport);
```

# 13. 关键稳定性设计

你真正要稳定的是这几层。

## 13.1 稳定结构

通过 schema 限制：

```text
hero
features
content
steps
faq
```

模型不能随便创造 HTML 结构。

---

## 13.2 稳定样式

通过固定 CSS 控制。

模型只能选择：

```text
modern-blue
minimal-gray
warm-orange
dark-tech
```

而不是自由写 CSS。

---

## 13.3 稳定文件格式

MCP Server 永远输出：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  ...
</head>
<body>
  <main class="page">
    ...
  </main>
</body>
</html>
```

这部分完全不由模型决定。

---

## 13.4 稳定代码格式

用 Prettier 格式化：

```ts
await prettier.format(html, {
  parser: "html",
  printWidth: 100,
  tabWidth: 2
});
```

---

## 13.5 安全写文件

限制只能写当前工作目录下的 `.html` 文件：

```ts
if (!fullPath.startsWith(cwd)) {
  throw new Error("path traversal is not allowed");
}

if (!fullPath.endsWith(".html")) {
  throw new Error("only .html files are allowed");
}
```

# 14. 你可以进一步加一个 Prompt 资源

MCP 不只是工具，也可以提供 prompts。

你可以加一个 MCP Prompt，用来指导 Agent 如何调用工具。

例如：

```ts
server.prompt(
  "generate_stable_html",
  "Generate stable HTML through the render_html_file tool.",
  {
    topic: z.string(),
    outputPath: z.string().default("output/index.html")
  },
  ({ topic, outputPath }) => ({
    messages: [
      {
        role: "user",
        content: {
          type: "text",
          text: `
请根据主题生成一个完整页面。

主题：${topic}
输出路径：${outputPath}

重要要求：
不要直接手写 HTML。
必须调用 MCP 工具 render_html_file。
将页面内容组织成结构化 page JSON。
          `.trim()
        }
      }
    ]
  })
);
```

这样你在编辑器里可以直接调用这个 prompt。

```text
render_html_file
```

```text
output/index.html
```

# 19. 我建议你的最终方案

你的项目可以命名为：

```text
mcp-html-renderer
```

核心定位：

```text
A local MCP server that converts structured page data into stable single-file HTML documents.
```

第一版重点：

1. 强 schema；
2. 固定模板；
3. 固定 CSS；
