 # Baseline Governance

 Baseline files capture the project context that shaped a plan or spec. They are not a replacement for the source code, README, or architecture document.

 ## Rules

 - Prefer existing authority documents when they are current.
 - Add a baseline snapshot only when a durable feature decision needs shared context.
 - Keep snapshots concise and evidence-based.
 - Do not treat a baseline as completion authority; runtime checks and tests remain required.
 - When implementation changes a public tool contract, update README and architecture notes as needed.
